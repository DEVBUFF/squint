# Squint

> Дизайнеры щурятся на экран (squint test), чтобы увидеть, что на самом деле бросается в глаза. Squint делает это для всего продукта.

**Арт-директор по UI/UX и брендингу для Claude Code прямо в твоём репозитории.** Каждый месяц собирает
актуальные тренды и учится *твоему* вкусу по доскам Pinterest и скриншотам. Аудирует веб-, iOS- и
Android-продукты: сначала даёт план и визуальные концепты «до / после», а меняет продукт только
после твоего согласия.

[English version](README.md)

```
/squint:setup                            # один раз: инструменты, первый мудборд, расписание
/squint:moodboard add https://pinterest.com/you/your-board/
«проанализируй мой проект и дай улучшения»
→ report.md + concepts.html (макеты до/после, оценки, направления, позиционирование)
«apply R1 R3 R5»                         # только теперь он трогает код
```

## Что умеет

| | |
|---|---|
| 🔭 **Ресерч трендов раз в месяц** | Параллельные скауты изучают **веб, iOS, Android и брендинг/позиционирование** с датированными источниками и отслеживают динамику от месяца к месяцу (new ↑ → ↓ fading). База поставляется с плагином и обновляется GitHub Action. Можно запускать и локально по расписанию. |
| 🎨 **Учится твоему вкусу** | Добавь доски Pinterest, ссылки Dribbble, Behance или сайтов, скриншоты или папки. Он изучает каждую картинку (палитра, шрифты, сетка, форма, настроение, фирменные приёмы) и ведёт **профиль вкуса**, который можно читать и править. Принятые и отклонённые рекомендации тоже его обучают. |
| 🔍 **Аудирует продукт** | Определяет стек (Next/React/Vue/Svelte, SwiftUI/UIKit, Compose/Views, React Native/Expo, Flutter) и снимает реальные скриншоты (браузер, iOS Simulator, Android-эмулятор). Оценивает UX, UI, доступность, соответствие платформе, бренд и позиционирование, а каждую оценку подкрепляет доказательством: `file:line`, скриншот, замеренный контраст, «долг» дизайн-системы. |
| 🖼 **Сначала показывает** | `report.md` содержит quick wins, основные и смелые изменения, у каждого указано обоснование (гайдлайн · id тренда · твой вкус · данные). `concepts.html` для каждого изменения ставит реальный скриншот «до» рядом с HTML-макетом «после» в рамке iPhone, Android или браузера. Галочками собираешь команду одобрения. |
| 🛠 **Внедряет по согласию** | Порядок: токены → компоненты → экраны → тексты. Работает в отдельной ветке, проверяет результат скриншотами «после», пишет журнал в `decisions.md`. |
| 📣 **И позиционирование** | 5-секундный тест, ресерч конкурентов, 2–3 варианта позиционирования, заголовки, страница в App Store и Google Play, тон голоса. |

Учитывает платформу. iOS оценивается по конвенциям и трендам iOS (например, актуальное поколение
Liquid Glass), Android — по Material 3 Expressive, веб — по WCAG 2.2, Core Web Vitals и веб-трендам.
Кроссплатформенные приложения он проверяет по принципу «единое ядро бренда + нативная оболочка
платформы».

## Установка

```bash
claude plugin marketplace add DEVBUFF/squint
claude plugin install squint@squint
```

Или внутри Claude Code: `/plugin marketplace add DEVBUFF/squint`, затем
`/plugin install squint@squint`. Перезапусти Claude Code и выполни `/squint:setup`.

**Нужно:** Claude Code, Python 3.9+, Node.js 20+ (встроенные MCP-серверы запускаются через `npx`),
Google Chrome. По желанию: Xcode (iOS Simulator), Android platform-tools и эмулятор, Pillow
(`pip install pillow`) для точного извлечения палитры.

**Обновления:** `claude plugin update squint@squint` или автообновление в `/plugin` →
Marketplaces.

## Кто за что платит

У Squint нет сервера и нет встроенных ключей. Всё, что он делает (аудит, `apply`, `learn`,
`positioning`, `research`), выполняется в **твоей сессии Claude Code**. Значит, токены идут из
**твоей** подписки Claude (Pro / Max) или с твоего API-ключа — смотря под чем ты залогинен.
Локальное ежемесячное расписание запускает `claude -p` под тем же логином.

Единственное, за что платит мейнтейнер, — общая база трендов. Раз в месяц GitHub Action собирает
тренды на подписке мейнтейнера, и все получают их со следующим обновлением плагина. Встроенные
MCP-серверы работают локально. Исключение — поиск Exa, но он работает на бесплатном лимите без ключа.

## Скиллы

| Команда | Можно и обычной фразой | Что происходит |
|---|---|---|
| `/squint:audit [фокус]` | «проанализируй мой проект и дай улучшения» | Полный аудит → `report.md` + `concepts.html`. Продукт не трогает. |
| `/squint:apply R1 R3` | «делай квик вины», «направление B» | Внедряет одобренное и проверяет результат скриншотами. |
| `/squint:moodboard add <url\|путь>` | «добавь мою доску», «вот что мне нравится» | Источники, синхронизация, скриншоты, папка inbox. |
| `/squint:learn` | «изучи мои референсы» | Разбирает новые референсы и пересобирает профиль вкуса. |
| `/squint:research` | «обнови тренды» | Ресерч трендов за месяц → `~/.squint/trends/<ГГГГ-ММ>/`. |
| `/squint:positioning` | «помоги с позиционированием», «перепиши оффер» | Варианты позиционирования, месседжинг, заголовки, стор, тон голоса. |
| `/squint:setup` | «настрой арт-директора» | Проверка инструментов, подключения, расписание, первый мудборд. |

## Как он учится

1. **Источники.** Доски Pinterest синхронизируются через RSS (за раз приходят 25 последних пинов;
   большие доски можно собрать через браузер). Ещё подходят ссылки на картинки и сайты, скриншоты и
   папка `~/.squint/inbox/`, в которой подпапки становятся тегами.
2. **Разбор.** Скилл `learn` смотрит каждую картинку и записывает палитру, типографику, сетку,
   радиусы и глубину, настроение, фирменные приёмы и то, почему тебе это, скорее всего, понравилось.
3. **Профиль вкуса** (`~/.squint/taste/profile.md`) содержит сильные сигналы в процентах и
   правила для арт-директора. Его можно править руками, и твои правки весят больше всего.
4. **Обратная связь.** Всё, что ты принял или отклонил в аудитах, записывается и учитывается.

Если сигналы спорят, приоритет такой: **бриф → доступность и гайдлайны платформы → мудборд проекта →
твой вкус → тренды**. Тренд — это инструмент, а не цель, и в каждом аудите есть список «сознательно не
рекомендуем».

- **Глобальный вкус** (`~/.squint/`) работает во всех проектах.
- **Мудборд проекта** (`<проект>/.squint/`, флаг `--project`) действует только для этого продукта.
- **Are.na** запрещает автоматический доступ, поэтому используй её официальный MCP со своим логином
  или сохраняй картинки в inbox.

## Ежемесячный ресерч: три уровня

1. **База в плагине.** GitHub Action `monthly-trends.yml` 1-го числа исследует четыре области,
   проверяет формат и открывает PR. После мержа обновление получают все.
2. **Твоя личная база.** `/squint:setup` ставит задачу в launchd (macOS) или cron (Linux) через
   `scripts/schedule.sh install`. 1-го числа запускается `claude -p "/squint:research"`, и
   заранее разрешены только инструменты ресерча.
3. **Напоминание.** Если база старше 35 дней, Claude предложит обновить её в начале сессии.

## Встроенные инструменты (запускаются сами)

| Сервер | Зачем | Ключ |
|---|---|---|
| `browser`: chrome-devtools-mcp | Скриншоты, эмуляция устройств и тёмной темы, Lighthouse-аудит доступности, трейсы производительности | не нужен (статистика и CrUX отключены) |
| `mobile`: mobile-mcp | iOS Simulator и Android-эмулятор: скриншоты, тапы, свайпы, флоу | не нужен (телеметрия отключена) |
| `exa`: Exa remote MCP | Семантический поиск трендов и конкурентов | не нужен (бесплатный лимит) |

Любой сервер можно отключить в `/mcp`. **По желанию** `/squint:setup` предложит подключить
Figma, Mobbin, Refero, Firecrawl, Are.na и MobileBuildMCP.

## Что остаётся в репозитории после аудита

```
.squint/
  brief.md                  продукт, аудитория, позиционирование, бренд, цели
  audits/2026-10-18/
    report.md               вердикт, оценки, находки, R-пункты, направления, позиционирование
    concepts.html           макеты до/после в рамках устройств + галочки одобрения
    screens/before|after/   реальные скриншоты
  decisions.md              что внедрено или отклонено и почему
```

## Данные и приватность

Всё хранится локально: `~/.squint/` и `<проект>/.squint/`, картинки референсов проекта по
умолчанию в `.gitignore`. В сеть уходят веб-поиск, страницы, которые ты просишь снять, и RSS тех
досок Pinterest, которые ты добавил. Скачанные картинки предназначены только для личного
референса, поэтому уважай правила сайтов.
